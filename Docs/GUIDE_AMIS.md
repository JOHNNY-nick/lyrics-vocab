# Tester Lyrics & Vocab — guide pour les amis

Lyrics & Vocab t'aide à retenir les mots anglais que tu entends dans tes chansons : tu ajoutes un mot, l'application trouve un extrait de chanson où il apparaît, le traduit, l'explique et te le fait réviser.

L'application est en test : elle fonctionne grâce au PC d'Arthur, qui fait tourner l'intelligence artificielle. Tu n'as rien d'autre à installer que l'application. Ta bibliothèque est **à toi seul** : personne d'autre ne voit tes mots.

**Il faut un téléphone Android** (l'application n'existe pas sur iPhone).

## 1. Installer l'application

1. Télécharge le fichier **lyrics-vocab.apk** envoyé par Arthur.
2. Ouvre le fichier. Android demande d'autoriser l'installation d'applications inconnues pour l'application qui l'ouvre (Fichiers, Chrome, WhatsApp…) : autorise-la, puis touche **Installer**. L'avertissement est normal pour une application hors Play Store.
3. Ouvre **Lyrics & Vocab**. Au bout de quelques secondes, l'écran **« Code d'invitation »** s'affiche : entre le code qu'Arthur t'a donné (de la forme **LV-XXXX-XXXX**), puis **Valider**.
4. Choisis tes artistes préférés, puis ajoute ton premier mot.

Le code n'est demandé qu'une fois. **Garde-le pour toi** : il ouvre ta bibliothèque.

Pour une nouvelle version, installe le nouveau fichier **par-dessus** l'ancien (sans désinstaller) : tu gardes tes mots.

**Variante avec Tailscale** (si Arthur t'a partagé son PC sur Tailscale) : installe Tailscale, connecte-toi avec le compte invité, active « Use Tailscale DNS » dans ses paramètres ; l'application n'a alors pas besoin de code.

## 2. Utilisation

- **Ajouter** : tape un mot anglais ; sa fiche se remplit en une dizaine de secondes (traduction, extrait, explication, phrases d'exemple).
- **Révisions** : chaque jour, des phrases à traduire en employant tes mots, à l'écrit ou à voix haute (bouton 🎤).
- **Notifications** : un de tes mots au hasard toutes les 2 h (Réglages → Notifications pour changer).
- Le détail de toutes les fonctions est dans le guide d'utilisation complet.

## Bon à savoir

- **Internet est nécessaire** pour ajouter des mots, faire les exercices et synchroniser. Les révisions déjà téléchargées marchent sans réseau.
- Le PC d'Arthur doit être allumé ; s'il ne l'est pas, l'application affiche « Ton PC est injoignable » : réessaie plus tard.
- Si plusieurs personnes l'utilisent en même temps, l'IA peut mettre quelques secondes de plus.
- Tes mots et tes réponses sont enregistrés sur le PC d'Arthur, dans une base séparée de celle des autres.
- Un souci ou une idée : dis-le à Arthur.
